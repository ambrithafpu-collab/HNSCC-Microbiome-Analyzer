\# HNSCC Microbiome Analyzer



\## Overview



A Python-based bioinformatics project for analyzing microbiome data from Head and Neck Squamous Cell Carcinoma (HNSCC) and control samples.



\## Features



\* Load microbiome abundance datasets

\* Calculate relative abundance

\* Generate microbial abundance plots

\* Calculate Shannon Diversity Index

\* Compare HNSCC and Control groups



\## Technologies



\* Python

\* Pandas

\* NumPy



\## Project Structure



data/ - microbiome datasets



src/ - analysis scripts



results/ - generated figures



\## Current Analyses



\* Relative abundance analysis

\* Shannon diversity analysis
